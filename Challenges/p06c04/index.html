Easy Java Mission: Caesar Cipher Automated Key Finder

A malware payload obfuscated its C2 server domain using a Caesar cipher with an unknown integer shift key k between 1 and 25. The intercepted encrypted string is:

String ciphertext = "CHYK{ofaf_hfjxfw_hnumjw_pjd_2026}";

Write a Java program that automatically tests candidate shift keys from 1 to 25, shifts alphabetic characters backward, identifies the valid plaintext starting with XCTF{, and prints the decrypted flag string.
